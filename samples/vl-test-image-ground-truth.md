# VL画像テスト 正解表（vl-test-image.png）

Qwen3-VL の画像プロンプト（quality-prompts.json の image_prompt）への回答を採点するための正解表。
画像は図形・文字をプログラムで描画したものなので、個数と内容はすべて確定している。

## 中身（正解）

| 要素 | 正解 |
|---|---|
| タイトル文字 | 「ローカルLLM 画像テスト」 |
| 赤い丸 | 5個 |
| 青い四角 | 3個 |
| 緑の三角 | 4個 |
| オレンジの星（右上の枠内） | 7個 |
| 日付の文字 | 「2026年11月4日」 |
| 大きな数字 | 42（紫色） |
| 英字テキスト | 「Vision Test」 |
| 下部の小さい文字 | 「この画像はテスト用です」 |
| 棒グラフ | 3本（左から紫・オレンジ・青緑）。一番高いのは中央のオレンジ |

## 採点の目安

- 個数（丸5／四角3／三角4／星7／棒3）を全部当てたら優秀
- 文字の読み取り（タイトル・日付・42・Vision Test）ができているか
- 棒グラフの「一番高いのは中央のオレンジ」まで言及できたら空間・比較の理解も良好
- 存在しない要素を足したら（ハルシネーション）減点ポイントとして記録する
